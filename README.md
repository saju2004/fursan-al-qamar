## 🛠️ Tech Stack & Architecture

- **Frontend:** React 18 with Vite
- **Styling:** Tailwind CSS with custom brand design tokens
- **Icons:** Lucide React
- **Routing:** React Router DOM v6+
- **API/Service Layer:** `src/services/apiClient.js` — clean abstraction ready for Node/Express or Firebase backend integration

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/saju2004/fursan-al-qamar.git

# Navigate to project directory
cd fursan-al-qamar

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
